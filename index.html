Paste a program below, or load a .json file. It replaces the program you train from; the built-in one stays available.

Format. counts is reps for that exercise — one rep per impulse. baseCounts is the transition rest between exercises, in impulse counts. Each day may carry its own impulse to override the global timing. image is the name of a built-in exercise to reuse its photos, a data URI, or a two-item array of data URIs — start position first, working position second. With two, the app alternates them in time with the impulse. Everything except name and counts is optional.
